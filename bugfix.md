# Bugfix Entry Point

The authoritative repair queue is [docs/03-bugfix-register.md](docs/03-bugfix-register.md). Test criteria are in [docs/12-testing-and-acceptance.md](docs/12-testing-and-acceptance.md); source evidence is in [SOURCE-EVIDENCE.md](SOURCE-EVIDENCE.md).

Each repair needs a reproduction, root-cause explanation, scoped patch and passing regression evidence. No item is marked fixed merely because its solution is described. A `/bugfix` label does not automatically execute any maintenance or database operation.
